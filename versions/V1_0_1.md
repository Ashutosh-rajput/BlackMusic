
Next Version: v1.0.1
======================

Release Date: <TBD>

Overview
--------
This file lists planned features, bug fixes, and notes for the next release (v1.0.1).

Bug Fixes (resolved)
---------------------
- Closing the app does not stop playback: fixed. When the app is closed, playback now stops and media resources are released.


Features (new)
---------------
- Auto-create playlist on receipt of shared playlist: when a playlist is shared to the device, the app will automatically create a new playlist and add all included songs.
- Add option to auto-accept downloaded shared songs into the library (configurable in Settings).

Known Issues
------------

- When a song is shared the app was opening unexpectedly: fixed. Sharing a song now triggers only the download/transfer flow (if applicable) and does not open the app UI.


Notes
-----
- QA should verify: closing app stops playback in all states (foreground, background, locked screen).
- QA should verify share workflows for: single song share, album share, playlist share — ensure app does not open unless user explicitly taps to open.
- Settings: add toggle for "Auto-create playlist from shared playlist" and "Auto-add downloaded shared songs".
